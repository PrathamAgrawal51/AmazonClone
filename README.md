# 🛒 Amazon Clone  

A responsive **Amazon Clone** built to showcase frontend development skills using **HTML, CSS, and JavaScript**. This project replicates the core design and functionality of the Amazon website, including product listings, a shopping cart, and a responsive layout.

## 🚀 Features  

- 🖥️ **Fully Responsive UI** – Adapts to different screen sizes for a seamless shopping experience.  
- 🔍 **Product Search & Listings** – Displays products with images, descriptions, and prices.  
- 🔗 **Navbar & Footer** – Fully functional navigation and footer similar to Amazon.  

## 🛠️ Technologies Used  

- **HTML** – Structuring the web pages.  
- **CSS** – Styling for an Amazon-like UI.  
- **JavaScript** – Handling interactions and dynamic features.
